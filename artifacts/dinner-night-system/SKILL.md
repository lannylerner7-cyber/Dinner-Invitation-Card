# Dinner Night visual language

Read docs/AGENTS.md and docs/references/component-inventory.md. Source: compact Dinner Night Invitation, retained in docs/references.

No prose design manual existed; these rules are inferred from its CSS and composition: Georgia heading/body, Trebuchet labels/actions, warm paper surface, terracotta ink, gold inset border, 400px compact card. Use the real native link semantics and a 44px touch target. Respect reduced motion. There is no original brand logo; Google is a third-party action mark, not the brand.

Dark and unsupported semantic/chart roles are derived. System fonts retain original fallbacks. Do not invent authentication or embed the invitation-specific video in shared primitives.

Do not apply this system to existing screens until the user approves.
